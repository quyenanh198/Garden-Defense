# Font (OFL)

Design system dùng **Fredoka** (heading, số lớn) và **Nunito** (body). Cả hai là SIL Open Font License, tải từ https://fonts.google.com/specimen/Fredoka và https://fonts.google.com/specimen/Nunito.

1. Tải, giải nén, copy vào thư mục này:
   - `Fredoka-Bold.ttf`
   - `Nunito-Regular.ttf`
   - `Nunito-Bold.ttf`
2. Bỏ comment mục `fonts:` trong `pubspec.yaml`.
3. `flutter pub get` rồi chạy lại.

Thiếu font → Flutter dùng font mặc định, không lỗi.
